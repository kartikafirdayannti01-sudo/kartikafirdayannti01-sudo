Tentang Saya

Berikut sedikit cerita tentang perjalanan dan cara saya bekerja.

Perkenalan diri. Nama saya Alya Rahma. Saya adalah Frontend Web Developer yang fokus membuat tampilan website yang bersih, rapi, dan mudah digunakan oleh siapa saja.

Latar belakang pendidikan. Saya belajar di bidang teknologi informasi dan mulai mengenal HTML dan CSS dari proyek kecil yang saya buat sendiri. Dari sana, saya terus berlatih dengan membangun halaman sederhana hingga website yang lebih lengkap.

Minat di bidang teknologi. Saya tertarik pada desain antarmuka, aksesibilitas, dan tampilan yang responsif. Saya percaya website yang baik harus nyaman dibuka di komputer maupun ponsel.

Tujuan dan motivasi belajar. Saya ingin terus memperdalam JavaScript dan alat bantu pengembangan modern. Motivasi saya sederhana: melihat ide berubah menjadi produk yang berguna bagi orang lain.
